Critical PRD gaps (fix before Executor)

These are design holes — not “work not done.” Leaving them invites missed ACs or lazy reuse of poll paths.

Must-fix items — APPLIED to GitHub PRDs (2026-07-30)

  1. #599 gate language — Body now blocked on A1 Speed (#601); US#30 clarifies A2 is not an exit gate. Emission persistence, Redis≠SoT, mutex, dry-run isolation ACs landed.
  2. #598 legacy→gold cutover — Maps public.analytics_kpi_envelopes (shop_id, kind) → gold.kpi_envelopes + compat view; first-slice DDL; webhook_raw_events fate; one-writer map; ops move of partitions as A0 exit AC.
  3. #601 forbid full poll on material path — Reusing _FUJIWA_POLL_STEPS / full poll / unbounded sync_analytics is out of AC. Locked webhook catalog + five metric_id keys.
  4. #601 negative AC (Speed/Batch split) — A1 must not defer/batch/coalesce beyond #68’s 15-min window for cost/fleet/I/O reasons — that is A2’s job. Silent OLTP→OLAP conflation is a Must-fix violation, not a naming hint.
  5. #599 emission + Redis SoT — Candidate vs surfaced persistence; Postgres SoT; Redis read-through for public gated GET only (Envelope Cache discipline).
  6. #599 dry-run isolation AC — Must not call /v1/executions / Partner tool workers; CI guard named.
  7. #602 Postgres I/O budget — Independent of Partner budget: knobs, defer reason codes, metrics, deep modules (StaggerScheduler, governors, mutex).
  8. #600 wording sync — Related-track lines updated to A0/A1/A2 split; live envelope swap gated on A1.
