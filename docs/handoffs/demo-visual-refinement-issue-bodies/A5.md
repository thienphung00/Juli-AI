## What to build
Implement seller-language **five-stage review flow**: Why → Analytics → Inputs → Preview → Approve for Recommendations detail. Polish stage headings, navigation, Analytics evidence links, prefilled editable Inputs/Preview fields, and Approve gate with existing approval flow to In Progress.

Uses existing Decision payload and per-workflow review stage definitions — no new backend intelligence. No internal workflow step names (`tool_name`, integration labels) in seller-facing UI.

## Acceptance criteria
- Review flow navigates Why → Analytics → Inputs → Preview → Approve with Vietnamese stage headings
- Analytics stage links to inspectable evidence; Inputs/Preview use prefilled editable seller fields
- Approve opens existing approval gate and routes to In Progress on success (behavioral tests updated)
- No backend jargon, FBS/confidence strings, or internal workflow step names render in seller UI
- Route transitions covered by behavioral tests; Preview → Approve path reachable
- Compatible with fixture and Phase 2.10 (#534) Decision read paths
- **In Progress execution detail UI unchanged** — only entry via Approve from review

- Recommendations list card layout (DVR-A4 — must land first)
- New recommendation engine or ranking
- Settings configuration UI
