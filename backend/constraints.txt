# Exact-pinned dependency lock for `pip install -e "./backend[dev]"` (issue #921).
#
# Why this file exists: backend/pyproject.toml declares floor/ceiling RANGES
# (the versions this codebase is designed to support). Without a lock, a fresh
# `pip install` resolves whatever is newest in-range at install time, so CI and
# a developer machine can silently install different versions of the same
# dependency graph — see #921 (fastapi 0.141.1/starlette 1.6.0 in CI vs.
# fastapi 0.128.0/starlette 0.50.0 on a dev machine changed `app.routes`
# semantics under `app.include_router()` and made a security-invariant test
# pass vacuously). This file pins every package (direct + transitive, main +
# `dev` extra) to one exact version so every install — local or CI — resolves
# identically. It is consumed via `pip install -e "./backend[dev]" -c
# backend/constraints.txt` everywhere the backend is installed
# (see .github/workflows/pr.yml and .github/workflows/release.yml).
#
# Source of truth for SUPPORTED ranges is backend/pyproject.toml; this file is
# generated from it and must stay within those ranges. A dependency bump is a
# reviewable diff to this file (regenerate, don't hand-edit).
#
# Regenerate (one-liner, run from repo root; needs Python 3.12 to match CI/
# `requires-python`; pip-tools installs into a throwaway venv — never globally):
#
#   python3 -m venv /tmp/lockenv && source /tmp/lockenv/bin/activate && pip install -q "pip==24.3.1" pip-tools && (cd backend && pip-compile --all-extras --no-header --output-file=../backend/constraints.txt pyproject.toml) && sed -E -i.bak 's/^([A-Za-z0-9_.-]+)\[[^]]*\](==.*)$/\1\2/' backend/constraints.txt && rm -f backend/constraints.txt.bak && deactivate && rm -rf /tmp/lockenv
#
# (The sed step is required because pip constraints files reject extras
# markers like `sqlalchemy[asyncio]==...` — "Constraints cannot have extras" —
# so bracketed extras are stripped from the pinned package name; the extra
# itself is still installed because backend/pyproject.toml requests it.)
#
# After regenerating: run `pip install -e "./backend[dev]" -c
# backend/constraints.txt` and the full `tests/unit` suite before committing —
# a lockfile that hasn't been tested is exactly the ambient-drift problem this
# file exists to prevent.
